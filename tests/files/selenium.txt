selenium
-----------
Selenium mimics human interaction with a computer by replicating actions like clicking buttons 
and typing text. 


History:
---------
*Selenium is an open-source suite for automating web browsers.

*Started around 2004 (Selenium Core, Selenium RC) and later evolved into WebDriver (Selenium 2) and then Selenium 4, which supports the W3C WebDriver protocol and CDP integration (Chrome DevTools).

*Used widely for functional / UI test automation across browsers (Chrome, Firefox, Edge, Safari, legacy IE).

Java Project 
-------------
If you are NOT using Maven, do it this way in an Eclipse Java project:

Requirements:
Java JDK installed.
Eclipse IDE (or other IDE).
Selenium client JARs (download from seleniumhq).
Browser driver executable (e.g., chromedriver.exe for Chrome).


Step-by-step (manual)
---------------------
*Create a new Java Project in Eclipse: File → New → Java Project.
*Create a package and class (e.g., selenium.OpenFacebook).
*Download Selenium Java (zip) from selenium.dev → extract → selenium-java-x.y.z.jar plus all libs in the libs folder.
*GoogleSelenium jar download download stable version Jar file
*Add JARs to project build path: Right click project → Build Path → Configure Build Path → Libraries → Add External JARs → select the JARs.
*Download ChromeDriver matching your Chrome version from chromedriver.chromium.org and place it in C:\drivers\chromedriver.exe (or another folder).

*In code set system property:
	System.setProperty("webdriver.chrome.driver", "C:\\drivers\\chromedriver.exe");
	WebDriver driver = new ChromeDriver();

*Run the Java class as a Java Application.
Note: Manual JAR approach is fine for quick demos but harder to manage versions and transitive dependencies — prefer Maven.


Disadvantages / Limitations of Selenium
---------------------------------------
	Not a full test framework — you need TestNG/JUnit for test management.
	Browser drivers and browsers must be matched (driver ↔ browser version).
	Not great for desktop apps or non-HTML content.
	Flaky tests possible due to timing, async loads, dynamic pages — needs waits.
	Requires maintenance when web pages change (locators brittle).
	IE support is legacy and deprecated by Microsoft — use Edge IE-mode when needed.
	Needs environment configuration for CI (drivers, headless, browser versions, proxies).

1.self
---------
It point the current tag or current node .

syntax
---------
//tagname[xpath]/self::*


driver.findElement(By.xpath("path"))

2.parent 
-----------
Traverse to the parent element from the current tag . 

syntax
-------
//tagname[xpath]/parent::*



3.Ancestor 
-------------
Traverse to the parent and also grandParents 

syntax
----------
//tagname[xpath]/ancestor::*



4.child 
-------
traverse to the child node from the current tag . 

syntax
--------
self tag path/child::*



5.descendant 
----------------
Traverse from the current tag to the child and grand child tags.


syntax
--------
self tag path/descendant::*



6.following 
--------------
Traverse all the tag which is present after the current tag .


syntax
--------
self tag path/following::*



7.Preceding 
--------------
Traverse all the tag which is present  before the current tag.

syntax
--------
self tag path/preceding::*



8.preceding-sibling 
-----------------------
Traverse the before sibling from the current tag.

syntax
--------
self tag path/preceding-sibling::*



9.Following-sibling 
-----------------------
Traverse the after sibling from the current tag.

syntax
--------
self tag path/following-sibling::*

package intro;

import org.openqa.selenium.By;
import org.openqa.selenium.Keys;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.interactions.Actions;

public class KeyboardAction {

	public static void main(String[] args) {
		
		WebDriver driver = new ChromeDriver();
		driver.get("https://en-gb.facebook.com/");
		WebElement email = driver.findElement(By.xpath("//input[@id='email']"));
	
	Actions act = new Actions(driver);
	act.sendKeys(email,"oranium").perform();
	
//	select the text (ctrl+a)
	
	act.keyDown(Keys.CONTROL).sendKeys("a").keyUp(Keys.CONTROL).build().perform();
	
//	ctrl+c
	
	act.keyDown(Keys.CONTROL).sendKeys("c").keyUp(Keys.CONTROL).build().perform();
	
	
//	tab
	act.sendKeys(Keys.TAB).perform();
	
//	ctrl+v
	
	act.keyDown(Keys.CONTROL).sendKeys("v").keyUp(Keys.CONTROL).build().perform();
	
//	tab
	act.sendKeys(Keys.TAB).perform();
//	tab
	act.sendKeys(Keys.TAB).perform();
	//enter 
	act.sendKeys(Keys.ENTER).perform();
	
	}
}

package intro;

import org.openqa.selenium.Alert;
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;

public class Alerts {
 public static void main(String[] args) {
	
	 WebDriver driver = new ChromeDriver();
	 driver.get("https://the-internet.herokuapp.com/javascript_alerts");
	 
driver.findElement(By.xpath("//button[text()='Click for JS Alert']")).click();
    Alert alert = driver.switchTo().alert();
    alert.accept();
    
    driver.findElement(By.xpath("//button[text()='Click for JS Confirm']")).click();
    Alert alert2 = driver.switchTo().alert();
    alert2.dismiss();
    
    driver.findElement(By.xpath("//button[text()='Click for JS Prompt']")).click();
    Alert alert3 = driver.switchTo().alert();
    alert3.sendKeys("hello");
    alert3.accept();
    
}
}
